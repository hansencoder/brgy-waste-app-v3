Build a responsive, mobile-first "Admin Dashboard" for "Wastewatch" (Administrator Portal) using React, Tailwind CSS, and Lucide icons based on the following specs:

---
### 1. MOBILE-FIRST & RESPONSIVE ARCHITECTURE
- Breakpoints:
  * Mobile (< 768px): Single column flow, hidden sidebar replaced by a sticky top header with hamburger menu, horizontally scrollable or stacked metric cards, and card-based data tables.
  * Tablet (768px - 1024px): 2-column grid layout for summary cards, collapsible sidebar overlay.
  * Desktop (>= 1024px): Fixed left sidebar (260px) + main scrollable content canvas, 3-column overview card grid.

- Mobile Navigation Behavior:
  * Fixed top navigation bar displaying the Wastewatch logo, "ADMIN PORTAL" badge, notification bell with badge "2", and a slide-out drawer trigger (hamburger icon).
  * Collapsible mobile drawer slides from left, styled in deep dark green (#07281E), containing full navigation links and administrator profile details.

- Mobile Layout Transformations:
  * 3-Column Summary Cards -> Stack vertically into 1-column cards on mobile.
  * Internal Card Metrics (e.g., 245 Total, 18 Pending...) -> Wrap into a 2-column grid or scrollable metric pill row on small screens.
  * Quick Access 6-Button Grid -> Collapses into a 2-column grid of large touch targets (minimum 48px height).
  * Data Table -> On mobile, converts to stacked list cards displaying: REPORT ID, CATEGORY, STATUS badge, and a primary "Review" CTA button. On desktop (>= 1024px), renders as full HTML <table> with horizontal scrolling (`overflow-x-auto`) fallback.

---
