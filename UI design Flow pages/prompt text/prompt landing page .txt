4. Strict Responsive Design Rules:
   - Mobile (< 640px):
     * Header navigation collapses into a mobile hamburger menu drawer (`fixed inset-0 z-50`).
     * Hero section text centers, CTA buttons stack vertically (`w-full`).
     * All 2-column and 4-column grids collapse into a clean single-column layout (`grid-cols-1`).
     * Smartphone graphic centers above or below the feature stack.
   - Tablet (640px - 1024px):
     * Grid layouts adapt to 2 columns (`md:grid-cols-2`).
   - Desktop (> 1024px):
     * Full multi-column asymmetrical layout with maximum container width constraint (`max-w-7xl mx-auto px-6`).
