Account SummaryDisplays:Full NameVerified Contact InformationAccount StatusQuick actions:Edit ProfileChange PasswordSubmit Waste Report ApproachThe Submit Waste Report module is the core feature of the Waste Reporting System. It enables residents to report waste-related concerns by providing the location of the incident, selecting standardized report information, and submitting supporting evidence. The reporting process is designed to be simple, consistent, and efficient while ensuring that the collected data is suitable for spatial analysis and decision-making.Before a report is accepted, the system performs several validation procedures, including barangay boundary validation, automatic purok identification, duplicate report detection, and report validation, to improve data quality and reduce redundant submissions.1. Accessing the Report FormResidents access the module by selecting Submit Waste Report from the Resident Dashboard.The system requests permission to access the device's location.If permission is granted, the system automatically detects the resident's current GPS location.If permission is denied, the resident may manually pin the report location on the interactive map.2. Report LocationThe resident identifies the location of the waste incident.The system provides:Interactive mapAutomatic GPS detectionManual map pinningAutomatic latitude and longitude retrievalOnce a location is selected, the system automatically performs geofence validation.If the selected location is outside the configured barangay boundary, the report cannot proceed.Example:The selected location is outside the barangay's service area. Please select a location within the official barangay boundary.If the location is valid, the system automatically determines the corresponding Purok using the configured polygon boundaries.Residents are not required to manually select their purok.3. Waste InformationAfter confirming the location, the resident provides the necessary report details.Waste Category (Required)The resident selects the type of waste concern.Examples include:Illegal DumpingOverflowing Garbage BinUncollected GarbageConstruction WasteYard WasteHazardous WasteOthersThe available categories are managed through the Waste Category Management module.Estimated Quantity (Required)The resident estimates the amount of waste using standardized options.Example:Small (1–2 garbage bags)Medium (3–5 garbage bags)Large (6–10 garbage bags)Very Large (More than 10 garbage bags)Using predefined options ensures consistency across reports and supports more meaningful statistical analysis.Waste Condition (Required)The resident selects the condition that best describes the reported waste.Examples include:Newly DumpedAccumulatingOverflowingScatteredBlocking DrainageBlocking RoadwayThese standardized conditions help the barangay assess the urgency and nature of the reported issue.Additional Remarks (Optional)Residents may provide additional information that cannot be expressed through the predefined fields.Examples include:"Beside the basketball court.""Located behind the blue gate.""Garbage has a foul odor."This field provides contextual information while keeping the reporting process primarily structured.Photo Attachment (Required or Optional)Residents upload one or more photographs of the waste.Whether photo submission is required or optional depends on the configuration set by the Administrator in the Report Settings module.Photographs assist in report verification and provide visual evidence of the reported concern.4. Automatic Duplicate DetectionOnce the location has been selected and the required information has been provided, the system automatically checks for existing reports using the configured:Duplicate detection radiusDuplicate detection time windowThe comparison considers:Distance between reportsWaste categoryReport statusDate and time submittedThis process helps reduce duplicate reports while still allowing residents to report genuinely different incidents.5. Nearby Existing ReportsIf similar reports are found, the system displays a popup containing anonymous nearby reports.The popup includes:Mini interactive mapResident's selected locationExisting report location(s)Approximate distanceWaste categoryReport statusDate reportedNumber of supportersNo personal information about the original reporter is displayed.Residents are presented with two options.Support Existing ReportIf the resident confirms that the existing report refers to the same issue:The resident's support is added to the existing report.The report's support count is increased.A new report is not created.The resident receives a confirmation that their support has been recorded.Continue New ReportIf the resident determines that the issue is different despite the nearby report:The popup is closed.The resident continues with the report submission process.This approach prevents unnecessary duplicate reports without restricting legitimate submissions.6. Report ValidationBefore the report is saved, the system validates:Required fieldsValid barangay locationValid waste categoryEstimated quantityWaste conditionFile typeMaximum upload sizeRate limitingDuplicate detection resultsIf any validation fails, appropriate error messages are displayed to allow the resident to correct the information.7. Report SubmissionAfter all validations have been successfully completed, the report is submitted.The system automatically:Generates a unique Report ID.Records the submission date and time.Stores the GPS coordinates.Associates the report with the logged-in resident.Assigns the detected Purok.Sets the initial report status to Pending Verification.Initializes the support count.Sends a notification confirming successful submission.8.
